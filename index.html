Prototype scope. This demo runs real geocoding, real live-weather cross-verification, real text-based event categorization and duplicate clustering, entirely in the browser, with a real interactive India map (Leaflet + OpenStreetMap). Bulk live social-media scraping and a shared multi-user backend are out of scope for a static client-side demo — see Platform Architecture inside the app for exactly what's real, what's simulated, and how this would scale in production, including a ready-to-build backend API contract.
